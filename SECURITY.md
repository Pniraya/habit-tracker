# Security Policy

Habit Tracker is a local-first app: it has no server, no account and no network permission. The
main security surface is therefore the local database and any file the user chooses to export.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting on this repository
(`Security` tab → `Report a vulnerability`). Do not open a public issue for a suspected
vulnerability, and do not include real habit data in a report.

## Supported versions

Only the latest commit on `main` is supported while the project is in development.
