## 1. Objective

## 3. Scope
- `StatisticsPresenter` 重写为「月热力图 + 周趋势 + 双摘要」模型，规则全部落在纯函数里。
- `StatisticsScreen` 按设计稿重建：颜色、圆角、间距、色阶、图例、今天描边。
- 底部导航栏改为设计稿的白底 + 绿色胶囊选中态。

## 4. Out of Scope
- **周/年切换**：设计稿有三个标签，但只实现「月」。未选中的两个标签**显式变淡**，不是可点但无反应的假按钮。
- 图标形状：设计稿用线性图标，本项目用 `material-icons-core` 的实心图标；换图标要加 `material-icons-extended` 依赖，属未批准依赖，未做。

## 6. Acceptance Criteria
- [x] 月网格周一开头、首日前补齐空格、今天有橙色描边
- [x] 色阶 0–4 与图例一致，且「1 个习惯当天完成」= 最深色（level 4），不是最浅色
- [x] 未来日期比「计划了但没做」更浅，两者不混淆
- [x] 完成率用总量相除（1/14 = 7%），不是各习惯百分比求平均
- [x] 周趋势在「今天」处截止，今天之后为 0
- [x] 真机截图与设计稿逐项对照

## 7. Risks
- 设计稿是静态图，色阶边界（1/4、1/2、3/4）是我按图例推断的，不是稿子里写死的规则。若期望不同，只需改 `level()` 一处。
