# ADR-013: 独立评审证据与仓库相对脚本路径

- 状态：`ACCEPTED`
- 批准方式：用户于 `2026-11-05` 指示“再次检查管理系统，若尚不完善帮我解决”；本 ADR 将发现的两项治理缺口转化为可验证规则。
- 日期：`2026-11-05`
- 关联：`AGENTS.md` §5、§7、§10、§12；`ADR-012`；`tools/check-governance.ps1`；`tools/close-task.ps1`

## 背景

ADR-012 要求 Reviewer 给出结论，但检查器只验证清单模板存在，无法证明任一已完成任务接受过独立评审。同时，`close-task.ps1` 的默认仓库路径写死为 `D:\AndroidStudio`，在其他工作副本运行可能修改错误目录。

## 决策

1. `TASK-007` 起，所有拟以 `DONE` 合入 `main` 的任务必须保留 `project/reviews/REVIEW-TASK-xxx.md`。记录必须写明审查 commit、Reviewer、独立性、清单结论与可复核证据；只有 `INDEPENDENT` 与 `APPROVE` 同时存在才满足合入门槛。
2. 历史任务不追溯补造独立评审记录。`TASK-006` 在本任务中由新会话独立复核并补录；`TASK-007` 的评审必须由后续独立会话完成。
3. 仓库内脚本默认从自身所在目录推导仓库根路径。调用者仍可用 `-Repo` 覆盖，供明确指定的工作副本使用。

## 后果

- 新增评审记录模板和检查器规则；缺失或非独立的评审记录会使治理检查失败。
- `TASK-007` 保持在功能分支，直到独立 Reviewer 留下 `APPROVE`。
- 这只约束治理流程，不改变产品需求、Android 架构或数据库 schema。
