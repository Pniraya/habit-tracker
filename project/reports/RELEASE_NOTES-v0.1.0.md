# Habit Tracker 0.1.0

首个可安装版本，`versionCode 1`。安装包见下方 Release 附件。

## 装上后会得到什么

- **五页完整闭环**：今日 / 新建 / 统计 / 我的 / 习惯详情，全部接真实数据库。
- **打卡**：布尔习惯一键完成；数值习惯按目标累加（如「30 分钟」「20 页」）。
- **04:00 日切**：凌晨 1 点补打昨天的卡，仍记在昨天，连续天数不会被截断。
- **自定义图标**：从相册选图，自动正方形裁切、修正拍摄方向，存为 256px 本地文件。
- **备份**：导出单个 JSON 文件（四张表全量）；导入为**覆盖式恢复**，先在内存完整校验，再单事务写库，失败整体回滚。
- **统计**：本周概览 + 近 5 周热力格子，详情页有月历打卡记录。

## 隐私

- **没有网络权限**。APK 里没有 INTERNET 权限，物理上无法上传任何数据。
- 没有账号、没有服务器、没有云同步、没有分析 SDK。
- 所有数据只在本机 Room 数据库；备份是你自己选择保存位置的明文 JSON。

## 已知限制

- 仅手机竖屏；平板/横屏未适配。
- 提醒功能未实现（本版本不含通知）。
- 只验证过 Android 15 真机（iQOO Neo7 SE）与模拟器；小米 HyperOS、OPPO ColorOS 等 OEM 系统未实测。
- 2.0× 超大字体下，详情页的周网格会换行、内容偏挤（不裁字，但需滚动）。

## 安装

1. 下载 `app-release.apk`。
2. 手机上允许「安装未知来源应用」。
3. 安装后直接打开，无需注册。

要求 Android 8.0（API 26）及以上。
