# Contributing

Thanks for looking at the project. It is currently developed as a personal project, so:

- **Issues are welcome** — bug reports with a reproduction, or a concrete feature proposal.
- **Pull requests are not accepted yet.** The repository uses an evidence-first process
  (`AGENTS.md`, `project/REVIEW_CHECKLIST.md`): every task records the commands it ran, and
  merging to `main` requires a build, the test suite and a review record. Opening a PR without
  that context would bypass the process rather than help it.

If you want to discuss the process itself, open an issue and describe the change you have in mind.
